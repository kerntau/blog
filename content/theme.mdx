## 主题特性

<CardList>
- **响应式设计和夜间模式**：支持移动端和桌面端，同时适配系统颜色偏好，确保在不同设备上都能提供良好的阅读体验。
- **高性能**：基于 Next.js App Router 架构，提供极速的页面加载和交互体验。
- **订阅源**：支持 Atom 订阅源，自动生成站点地图和 RSS 订阅。
- **SEO 优化**：全方位的 SEO 适配，包括动态 OG 图像生成和结构化数据。
</CardList>

### 减少干扰

<CardList>
- **清晰易读**：选用容易阅读的字体和合适的字号，采用不刺眼且易于辨识的颜色搭配。
- **专注文章**：避免无意义的动画干扰，让读者回归阅读本质。
</CardList>

## 开源与衍生

- 灵感源自原 Nuxt 版本的 [L33Z22L11/blog-v3](https://github.com/L33Z22L11/blog-v3)。
- 借鉴了众多优秀设计，结合当前 Next.js 生态进行重构与增强。

### 技术架构

<CardList>
- 主要框架与语言
  - **前端框架**：Next.js 15
  - **开发语言**：TypeScript + React 19 + SCSS
- 内容与服务
  - **内容管理**：MDX + Local File System
  - **部署平台**：Vercel
  - **包管理器**：pnpm
- 工具库
  - **动画引擎**：Framer Motion
  - **代码高亮**：Shiki
  - **时间处理**：Temporal API
  - **状态管理**：Zustand / Jotai
</CardList>
